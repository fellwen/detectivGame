# Последняя ночь в отеле Грейс

Интерактивная детективная игра.

Сеттинг:

Альпы, зима 1928 года.

Игрок расследует убийство миллионера Аркадия Вельского
в изолированном из-за снежной бури отеле.

Главная особенность:

Сержант Кот, который ведёт расследование, сам является убийцей.

---

## Технологии

- HTML5
- CSS3
- JavaScript ES Modules
- Bootstrap 5.3.3
- LocalStorage — будет использоваться для сохранений

---

## Запуск

Проект использует JavaScript ES Modules.

Поэтому не рекомендуется открывать index.html
через двойной клик как file://.

Используйте локальный сервер.

Например:

### VS Code

Установить расширение Live Server.

После этого:

ПКМ по index.html
→ Open with Live Server

## Главная игровая логика

Настоящий убийца:

Сержант Кот.

Для его разоблачения игроку необходимо собрать
достаточное количество независимых доказательств.

Ключевые доказательства:

1. Бутылка с цианидом.
2. Следы на замке.
3. Настоящее время смерти.
4. Свидетель возле кабинета.
5. Перчатка с цианидом.
6. Компрометирующие документы.
