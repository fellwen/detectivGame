# Последняя ночь в отеле Грейс

Интерактивная браузерная детективная игра на HTML, CSS, JavaScript ES modules и Bootstrap 5.3. Тема: коричневый, тёмно-синий и чёрный; стилистика полицейского архива 1928 года.

## Запуск

Из-за JavaScript ES modules проект лучше запускать через локальный HTTP-сервер, а не двойным кликом по `index.html`.

**VS Code:** установите расширение Live Server, откройте папку проекта и нажмите **Go Live**.

**Python:** из папки проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Структура

- `index.html` — базовая разметка и подключение Bootstrap.
- `css/style.css` — палитра, типографика, общие компоненты.
- `css/game.css` — экраны расследования, карточки, документы, этапы.
- `js/data/` — данные персонажей, улик, диалогов и этапов.
- `js/modules/` — сохранение, работа с уликами, допросы и задания этапов.
- `js/app.js` — точка входа, маршрутизация экранов и обработчики действий.
- `assets/images/` — место для будущих фотографий.

## Что реализовано

- Главный экран дела и навигация по разделам.
- Четыре последовательных этапа расследования.
- Семь досье персонажей и протоколы допросов.
- Карточки и модальные окна для документов и улик.
- Осмотр четырёх помещений с доступными на текущем этапе материалами.
- Проверка ответов с обратной связью и разблокировка следующих этапов.
- Заметки игрока по персонажам и этапам.
- Сохранение прогресса в `localStorage`.
- Итоговое обвинение и финал при правильном выборе.
- Адаптивная верстка и базовое экранирование пользовательского ввода перед вставкой в HTML.

## Добавление фотографий

Положите изображения в `assets/images/rooms/`, `assets/images/characters/` или `assets/images/evidence/`. Заглушки фотографий намеренно оставлены до получения оригинальных изображений. Следующим шагом можно заменить их реальными фотографиями и добавить просмотр нескольких ракурсов с временными метками.

## Примечания

Это клиентский прототип: прогресс хранится только в текущем браузере и не синхронизируется между устройствами. Контент и правильные ответы доступны в клиентском коде, поэтому это игра для одиночного прохождения, а не защищённая многопользовательская система.
